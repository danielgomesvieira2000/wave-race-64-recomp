# A scripted two-player race: both players from boot into a 2P VS race start.
#
# Written to reproduce the race-start interpolation burst, which is worst in two
# players. Same format as race.txt (see src/testdrive.cpp), plus one addition:
# buttons prefixed with "2:" are player two's. A script that mentions player two
# makes the port report a second controller connected, so this runs with one pad
# or none.
#
# The main menu reads CHAMPIONSHIP, TIME TRIALS, STUNT MODE, 2P VS., OPTIONS,
# with the cursor on the first; 2P VS. is three steps down. After that every
# screen takes A to confirm, so both players tap A until the race and then hold
# it. A is never Start once the menus are past: Start would pause the race.
#
# The state transcript in the log says which press landed: grep it for "state:".

3.0    3.4   START          # Start (title, while it animates in; may not land)
7.0    7.4   START          # Start (title) -- the one race.txt relies on

12.0   12.4  -       0 -60  # stick down (2P VS.)
13.5   13.9  A              # choose 2P VS.
