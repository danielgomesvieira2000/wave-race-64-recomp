# Wave Race 64: Recompiled 0.7.1

A small release on top of [0.7.0](0.7.0.md): three more widescreen elements
placed correctly, and a known-issues list that had been carrying things which are
either fixed or were never faults.

**You need your own dump of Wave Race 64 (USA) (Rev A), also called v1.1**
(revision 1, header CRC `0x492F4B61 0x04E5146A`). No other version works. The
launcher checks the file you pick.

## Download

`WaveRace64Recomp-0.7.1-windows-x64.zip`: unzip anywhere, run
`WaveRace64Recomp.exe`, pick your dump. Settings, saves and mods go to
`%LOCALAPPDATA%\WaveRace64Recomp`, and so does `wr64.log`, the file to attach to
a bug report. Settings, mods and saves from 0.7.0 carry over unchanged.
`WaveRace64Recomp-0.7.1-windows-x64-debug-symbols.zip` holds the debug symbols
for the same executable, only needed for a readable crash report.

The zip contains the recompiled game code and none of the game's assets; the
executable is a GPL-3.0 combined work (see the README's *Licensing*), and its
source is this repository at tag `v0.7.1`.

## What changed

**Three more 2D elements placed correctly**, found with the debug menu on **F1**
and tagged into the port's built-in table, where they reach every player rather
than only the machine that found them. That brings the built-in table to
twenty-eight entries.

**The results screen's HUD layout is fixed**, which had been listed as a known
issue since 0.3.0.

**Every course has now been played** in both directions. The caveat about
untested courses, stunt mode and the championship ceremony is gone.

## Known issues, revised

Two things left the list because they were never faults, and two because they
were fixed or are no longer worth listing:

- **The 4:3 letterbox is not a bug.** The game draws a 303x199 region of its
  320x240 framebuffer and always did — those are the overscan borders a CRT hid.
  In a 4:3 window they show as bars. Fullscreen on a widescreen display, the
  default, has none. It is not going to change, so it is recorded as a note
  rather than an issue.
- **The results screen** is fixed.
- **The announcer volume** is off the list. Music and effects have their own
  sliders because the game keeps them on separate sequence players; the voice is
  not separable the same way, and that is a property of the game rather than
  something outstanding. The investigation is still written up in
  [PORTING.md](../PORTING.md), *Separating one sound from another*, for anyone
  who wants to try.
- **Course coverage** is no longer a caveat.

What remains:

- The wipe between the rider-select and course-overview screens stays boxed in
  the middle 4:3. Two triangle calls in one perspective group with no rectangles
  in it, which is why rectangle attributes never touched it; written up in
  [PORTING.md](../PORTING.md).
- The MAX POWER banner loses its last letter while the HUD layout is on. The
  game's own rectangle clips it, not the frame's edge.
- Windows is what this project builds and tests today. A fork carries native
  macOS support; wider platform coverage is intended.
