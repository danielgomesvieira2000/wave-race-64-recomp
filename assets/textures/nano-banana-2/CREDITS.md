# HD texture pack credits

Wave Race 64 and its original visual designs are the work of Nintendo and the
original game's artists. Kawasaki and Jet Ski branding belongs to its respective
owners. The replacements retain and adapt that source artwork; they are not
originally independent designs licensed under the code repository's MIT license.

Brian Tate directed the visual review and supplied the final eight dark-visor
helmet portraits. Codex prepared texture captures, atlas reconstruction,
source-layout fitting, icon and lettering refinement, and runtime integration.
The main image-generation workflow used Nano Banana 2. Generated candidates
that changed important designs were corrected locally or replaced by
source-preserving artwork; not every texture contains generated detail.

The two Wave Race logo variants use larger reference artwork from the
[LaunchBox Wave Race 64 image catalog](https://gamesdb.launchbox-app.com/games/details/392-wave-race-64-kawasaki-jet-ski),
fitted to their original texture regions. No ownership of the underlying logo
is claimed by this project.

Some glyph and number refinements were rendered using locally installed
Helvetica, Arial Narrow, and Courier New fonts. Font files from that workflow
are not distributed in this pack. The game's original lettering identities,
colors, placement, and texture mappings were used as references.

`manifest.json` records each shipped replacement's dimensions and SHA-256.
The pack contains rendered replacements and their mapping database. It does
not include a ROM, original texture dumps, generation-account data, or saves.
